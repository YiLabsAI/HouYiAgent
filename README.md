# HouYi 🏹

> **Next-generation lightweight multi-agent framework with industry-leading capabilities.**

HouYi aims to be the next-generation, industry-leading lightweight multi-agent programming framework. Compared to existing frameworks, HouYi offers the following advantages:

## ✨ Key Features

### 🪶 Lightweight by Core
Core programming model uses Pydantic for declarative definitions. Agent, Task, Flow, Router, and Tool are all defined as simple Python classes, seamlessly inheriting Pydantic's data validation, serialization, and documentation generation capabilities - achieving "code as documentation, code as configuration."

### 🔄 Bidirectional Visual Sync
Provides a visualization interface isomorphic with backend state, allowing developers to observe execution flow and directly modify the runtime graph through drag-and-drop and configuration. Changes sync back to the backend in real-time, achieving "what you see is what you get" AI orchestration and debugging.

### ⚡ Distributed High-Performance Execution
Architecture natively supports smooth scaling from single-machine multi-threading to distributed clusters. Task DAGs can be intelligently split and scheduled for execution to support high-concurrency, low-latency enterprise-grade requests.

### 🔍 Full-Stack Observability
Built-in observability system based on OpenTelemetry (OTEL), automatically generating unique Traces for every Agent execution, spanning LLM calls, tool execution, internal state transitions, and all other aspects. Provides out-of-the-box logging, metrics, and distributed tracing capabilities.

### 📊 Multi-dimensional Evaluation & Simulation
Built-in adversarial testing and simulation sandbox, supporting full-chain quality assessment from unit tests to end-to-end dialogue simulation, ensuring stability and measurability of Agent capability iterations.

### 🔒 Secure Sandbox Integration
Provides an isolated, permission-restricted secure sandbox environment for tool and code execution. Effectively prevents malicious or dangerous code generated by LLMs from damaging the host system, ensuring security in enterprise production environments.

### ✓ Verifiable & Deterministic
Through natively integrated neuro-symbolic architecture, decouples non-deterministic LLM generation tasks from deterministic symbolic execution tasks. Introduces formal verification nodes, allowing property verification of AI-generated plans and outputs, achieving business logic-level reliability.

### � Advanced Context Engineering
Provides powerful dynamic context manager, integrating RAG and multiple long-context processing strategies. Introduces reusable "Skills" as higher-level abstractions, making Agent capabilities versionable, shareable, and iterable like software libraries.

### 🌊 Asynchronous Streaming I/O Model
Framework I/O defaults to asynchronous streaming, supporting multiple event source inputs through pluggable Connectors, and pushing final results and intermediate thinking processes to clients in real-time as data streams, achieving ultimate interactive experience.

### 💾 Persistent State & Long-Running Workflows
Automatically creates persistent snapshots of Agent execution state, ensuring tasks can be interrupted and precisely resumed. Natively supports workflow pause, waiting for external events (such as async callbacks), and automatic wake-up after human intervention (Human-in-the-Loop).

### 🎯 Adaptive Optimization & Cost Governance
Built-in meta-learning module that autonomously optimizes workflows, prompt templates, skills, and tool selection by analyzing historical execution data and user feedback, enabling Agents to continuously evolve during use. Strictly controls operational costs through Token budget control and dynamic model degradation.

### 🔌 Middleware Ecosystem
Provides clearer abstractions with less boilerplate code. Designs an elegant Middleware Plugin mechanism, allowing community and third-party developers to easily contribute new tools, model adapters, data connectors, and validators, building a thriving ecosystem together.

## 🚀 Quick Start

### Basic Usage

```python
from houyi import Agent, tool

# 1. Define a skill
@tool
def search(query: str) -> list[str]:
    """Search the web for information."""
    return [f"Result for {query}"]

# 2. Create an agent (2 lines!)
agent = Agent(role="Researcher", skills=[search])

# 3. Run it
result = agent.run("What is HouYi?")
# Output: ✅ agent.run (13.16ms)
```

### With LLM Integration

```python
from houyi import Agent, tool
from houyi.llm import OpenAIAdapter

@tool
def calculate(expression: str) -> float:
    """Calculate a mathematical expression."""
    return eval(expression)

# Create agent with LLM
agent = Agent(
    role="Math Assistant",
    skills=[calculate],
    llm=OpenAIAdapter(model="gpt-5", api_key="...")
)

result = agent.run("What is 25 * 4 + 10?")
```

### Multi-Agent Team

```python
from houyi import Agent, Task, Team, tool

# Define agents
researcher = Agent(role="Researcher", skills=[search])
analyst = Agent(role="Analyst", skills=[analyze])

# Create team with tasks
team = Team(
    agents=[researcher, analyst],
    tasks=[
        Task("Research AI trends", agent=researcher),
        Task("Analyze findings", agent=analyst, context=[0])
    ]
)

result = team.run()
```

### Evaluation (19 Evaluators)

```python
from houyi import Agent, evaluate

# Run evaluation
results = evaluate(
    agent=agent,
    test_cases=[
        {
            "input": "What is AI?",
            "expected_output": "AI is artificial intelligence."
        }
    ],
    evaluators=[
        # Quality
        "accuracy", "completeness", "relevance", "semantic_similarity",
        # Performance
        "cost", "latency",
        # Safety
        "toxicity", "hallucination",
        # Behavior
        "skill_usage",
        # Advanced
        "llm_judge"
    ]
)

print(results.summary())
# Evaluation Results:
#   Total Cases: 1
#   Passed: 1 (100.0%)
#   Avg Score: 0.85
```

## 🎯 Advanced Features

### 1. Observability (Zero-Config)

HouYi includes built-in tracing with **< 3% performance overhead**:

```python
# Default: Console output (simple)
agent = Agent(role="Researcher", skills=[search])
result = agent.run("Query")
# Output: ✅ agent.run (13.16ms)

# Verbose mode with detailed traces
agent = Agent(
    role="Researcher",
    skills=[search],
    observability={
        "enabled": True,
        "exporters": [
            {"type": "console", "verbose": True},
            {"type": "json", "filepath": "traces.json"},
            {"type": "jaeger", "endpoint": "http://localhost:4318"}
        ]
    }
)
```

**Supported Exporters**:
- ✅ **ConsoleExporter**: Simple/verbose console output
- ✅ **JSONExporter**: Export to JSON file
- ⚠️ **JaegerExporter**: Placeholder (coming soon)
- ⚠️ **DatadogExporter**: Placeholder (coming soon)

### 2. Multi-LLM Support

Unified interface for multiple LLM providers:

```python
from houyi.llm import OpenAIAdapter, AnthropicAdapter

# OpenAI
agent = Agent(
    role="Assistant",
    skills=[...],
    llm=OpenAIAdapter(
        model="gpt-5",
        api_key="sk-..."
    )
)

# Anthropic
agent = Agent(
    role="Assistant",
    skills=[...],
    llm=AnthropicAdapter(
        model="claude-3-5-sonnet",
        api_key="sk-ant-..."
    )
)
```

**Features**:
- Streaming support
- Function calling
- Automatic retry with exponential backoff
- Pydantic validation

### 3. DAG Execution Engine

Parallel execution with dependency management:

```python
from houyi import Agent, Task, Team

team = Team(
    agents=[agent1, agent2, agent3],
    tasks=[
        Task("Task 1", agent=agent1),           # Runs first
        Task("Task 2", agent=agent2),           # Runs in parallel with Task 1
        Task("Task 3", agent=agent3, context=[0, 1])  # Runs after Task 1 & 2
    ]
)

result = team.run()
```

**Features**:
- Topological sorting
- Concurrent execution (asyncio)
- Dependency tracking
- Cycle detection

10 built-in evaluators across multiple dimensions:

```python

# Quality evaluators
quality_results = evaluate(
```

**All 19 Evaluators**:
- **Quality**: Accuracy, Completeness, Relevance, SemanticSimilarity
- **Performance**: Cost, Latency
- **Safety**: Toxicity, Hallucination, Safety
- **Bias & Facts**: Bias, Factuality
- **RAG**: Groundedness, ContextPrecision, ContextRecall, Faithfulness
- **Structure**: Coherence, SkillUsage
- **Advanced**: LLMJudge, Custom

### 5. Custom Evaluators

Extend with your own evaluation logic:

```python
from houyi import Evaluator, EvaluationResult

class CustomEvaluator(Evaluator):
    @property
    def name(self) -> str:
        return "custom"
    
    def evaluate(self, input, output, expected, metadata):
        score = self.calculate_score(output, expected)
        return EvaluationResult(
            evaluator=self.name,
            input=input,
            output=output,
            expected_output=expected,
            score=score,
            passed=score > 0.8,
            feedback=f"Custom score: {score:.2%}"
        )

# Use it
results = evaluate(agent, test_cases, evaluators=[CustomEvaluator()])
```

## 📚 Core Concepts

### Agent
Runtime instance with execution capabilities. Automatically integrates:
- **DAG Planning**: Intelligent task decomposition
- **Tracing**: Zero-config observability
- **LLM Integration**: Optional OpenAI/Anthropic support

```python
agent = Agent(
    role="Researcher",
    skills=[search, analyze],
    llm=OpenAIAdapter(model="gpt-4"),  # Optional
    observability={"enabled": True}     # Default: True
)
```

### Skill
Function wrapper with Pydantic validation:
- `@tool` decorator (auto-infers schemas from type hints)
- Input/output validation
- Automatic retry and timeout

```python
@tool
def search(query: str, max_results: int = 10) -> list[dict]:
    """Search the web."""
    return [...]
```

### Task
Task specification with dependencies:
```python
Task(
    description="Research topic",
    agent=researcher,
    expected_output="A report",
    context=[0, 1]  # Depends on task 0 and 1
)
```

### Team
Multi-agent orchestration with DAG execution:
- Parallel execution of independent tasks
- Dependency management
- Context passing between tasks

### Evaluation
19 built-in evaluators (Strategy Pattern):
- **Quality**: Accuracy, Completeness, Relevance, SemanticSimilarity
- **Performance**: Cost, Latency
- **Safety**: Toxicity, Hallucination, Safety
- **Bias & Facts**: Bias, Factuality
- **RAG**: Groundedness, ContextPrecision, ContextRecall, Faithfulness
- **Structure**: Coherence, SkillUsage
- **Advanced**: LLMJudge, Custom
