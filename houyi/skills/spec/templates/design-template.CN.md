### 核心设计原则

- **SDK 为基石**：核心能力在 SDK 层设计与实现，上层应用通过 SDK 构建，实践中反馈需求以驱动 SDK 持续演进
- **场景验证**：以真实产品场景验证 SDK 设计的合理性，暴露不足并推动迭代
- **工业级品质**：可量化指标为设计质量的最终衡量标准
- **增量交付**：每阶段交付完整可用的产品能力
